# Skills & Technical Expertise — Leo Zuze

## AI Agents, RAG & LLM Systems (current specialization)

This is Leo's primary area of focus right now and the core of his positioning as an AI fintech developer.

- **Retrieval-Augmented Generation (RAG)** — building pipelines that ground LLM responses in real, external data instead of relying on the model's training data alone, reducing hallucination and enabling systems to answer from private or up-to-date sources.
- **AI Agents** — designing agents that go beyond single-turn chat: deciding which tool to use, executing it, evaluating the result, and continuing until a task is complete.
- **LangChain** — building RAG applications and agent workflows, including retriever chains and interactive interfaces.
- **LlamaIndex** — document indexing and retrieval for RAG applications, as an alternative/complement to LangChain.
- **Vector databases & similarity search** — working knowledge of how embeddings, vector search, and indexing (e.g. ChromaDB) power retrieval.
- **LLM APIs** — integrating large language model APIs (Anthropic, OpenAI, and free-tier hosted inference such as Groq and Gemini) into real applications.
