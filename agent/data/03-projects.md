# Live Projects

## NevuX (SkyScout)

**Live:** https://skyscout-sepia.vercel.app
**Stack:** Python backend, React frontend, SerpAPI, AviationStack, Geoapify, OpenStreetMap, Mapillary, Wikipedia, Leaflet

A full-stack travel platform for people who love to travel — find flights, discover places, and explore destinations in one tool. Combines live flight search (SerpAPI, AviationStack) with places and mapping data (Geoapify, OpenStreetMap, Mapillary, Wikipedia, Leaflet) so it goes beyond a simple flight tracker into a genuine trip-exploration experience.

## Jamco Builders

**Live:** https://jamco-builders.vercel.app

A website for a construction company, built to showcase their completed work and let prospective customers get a quote directly through the site. A real client-facing project combining a polished portfolio/showcase experience with a functional lead-generation flow (the quote request).

## Talitha Cumi Accessories

## Nexus Lending

**Status:** Concept project, not deployed anywhere.
**Stack:** React 19, Vite, Tailwind CSS, Framer Motion, AOS, Lucide React

A fintech lending platform concept designed around the idea of using AI and alternative data to make credit access faster and fairer for people underserved by traditional banking. What exists is the front-end: a landing-page experience covering faster loan-approval messaging, transparent loan terms, a mobile-friendly interface, and trust messaging. There is no live credit-scoring model or lending backend behind it.

It reflects Leo's core thesis (AI-driven financial access), but it is a design and front-end concept, not a working product.
